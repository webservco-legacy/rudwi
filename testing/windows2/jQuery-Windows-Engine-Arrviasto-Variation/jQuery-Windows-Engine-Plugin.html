jQuery Windows Engine (jqWindowsEngine)

  • Windows Engine API
  • Examples
  • Download
The jQuery Windows Engine Plugin allows you to easily create ajax windows.

This is how you create a new window:

$("#example1").newWindow({ ajaxURL: "ajaxcontent.html" });

API

$("#example1").newWindow({
 windowTitle : "",
 content: "",
 ajaxURL: "",
 width : 200,
 height : 200,
 posx : 50,
 posy : 50,
 onDragBegin : null,
 onDragEnd : null,
 onResizeBegin : null,
 onResizeEnd : null,
 onAjaxContentLoaded : null,
 statusBar: true,
 minimizeButton: true,
 minimizeIcon: "-",
 maximizeButton: true,
 maximizeIcon: "O",
 closeButton: true,
 closeIcon: "X",
 draggable: true,
 resizeable: true,
 resizeIcon: "#"
});
